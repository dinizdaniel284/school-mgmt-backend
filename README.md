# School Management System - Backend API

This repository contains the backend infrastructure for the School Management System, developed using Node.js and Express.

## Technical Highlights

- **Advanced ACL:** Endpoint /api/v1/access-controls/me fully operational.
- **CORS Rules:** Hard-mapped to allow credentialed production requests.
- **Asset Normalization:** Case-insensitivity middleware handler inside app.js.
- **Frontend Notice:** The backend serves compliant payloads. Live deployment is healthy.
